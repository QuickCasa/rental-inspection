# Changelog

Notable changes to the app are recorded here. The format follows
[Keep a Changelog](https://keepachangelog.com/en/1.1.0/).

## 1.0.0 - 2026-10-03

First open source release.

- Move-in, move-out and routine inspections, room by room, with good, fair,
  poor and not applicable ratings, notes and photos for every item.
- Six starting rooms, 14 room types to add, and rooms and items that can be
  renamed, added or removed.
- Photos scaled down and saved as JPEG on the device, with the time each was
  added.
- On-screen signatures for the landlord or agent and each tenant, with the
  time each was made. The first signature locks the report.
- Move-out inspections started from a move-in show each item's move-in rating,
  and the report lists everything rated worse.
- A PDF report with the details, a checklist for each room, comments,
  signatures and numbered photos.
- Backup files that hold an inspection and its photos.
- Works offline after the first visit, with an update banner for new versions.
